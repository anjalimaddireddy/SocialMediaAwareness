# 📊 Social Media Awareness & Digital Behavior Analysis

## 🧠 Overview
This project analyzes social media usage patterns, awareness levels, cyber safety practices, and productivity impact among users. It is designed as a data analysis case study using Excel and visualization techniques.

The goal is to understand how digital behavior affects daily life and productivity.

---

## 🎯 Objectives
- Analyze social media usage patterns
- Study cyber safety awareness levels
- Understand screen time behavior
- Measure productivity impact of social media usage

---

## 📁 Dataset Information
- Total Records: 50 samples
- Features:
  - Age
  - Gender
  - Daily Screen Time
  - Platform Used (Instagram, YouTube, WhatsApp, Facebook)
  - Awareness Level (High, Medium, Low)
  - Cyber Safety Practice (Yes/No)
  - Productivity Impact (High, Medium, Low)

---

## 🛠 Tools Used
- Microsoft Excel
- Data Cleaning (Text to Columns)
- Data Analysis (COUNTIF, AVERAGEIF)
- Data Visualization (Pie Chart, Bar Chart, Column Chart)

---

## 📊 Analysis Performed
- Platform usage distribution analysis
- Screen time behavior analysis
- Awareness level classification
- Cyber safety practice evaluation
- Productivity impact comparison

---

## 📈 Key Insights
- Instagram is the most used platform among users
- Most users spend 4–6 hours daily on social media
- Awareness levels are moderate overall
- Cyber safety practices are followed by most users
- High screen time negatively affects productivity

---

## 📊 Visualizations
The project includes the following charts:
- Pie Chart → Platform usage distribution
- Bar Chart → Screen time analysis
- Column Chart → Awareness and productivity comparison

---

## 📌 Project Outcome
This project helps understand the impact of social media on behavior, awareness, and productivity. It can be useful for digital marketing, HR analysis, and social research studies.
